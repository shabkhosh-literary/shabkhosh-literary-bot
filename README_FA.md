# ربات رایگان انجمن ادبی شب خوش

این نسخه بدون OpenAI API و Railway است. پست‌ها از متن‌های نمونه داخل `bot.py` انتخاب می‌شوند. هیچ تضمینی برای اجرای دقیق در دقیقه مقرر وجود ندارد؛ GitHub Actions ممکن است اجرای زمان‌بندی‌شده را با تأخیر انجام دهد.

## فایل‌ها
- `bot.py`: منطق ربات
- `.github/workflows/schedule.yml`: اجرای زمان‌بندی‌شده هر ۵ دقیقه
- `data/`: وضعیت پیش‌نویس‌ها و تأییدها

## راه‌اندازی
1. مخزن GitHub را **Public** بسازید تا استفاده از runnerهای استاندارد Actions در مخزن عمومی رایگان باشد. کد این پروژه نباید حاوی هیچ رمز یا توکنی باشد.
2. این فایل‌ها را در مخزن بارگذاری کنید و مطمئن شوید شاخه پیش‌فرض (معمولاً `main`) شامل فایل workflow است.
3. در مخزن بروید به Settings → Secrets and variables → Actions → New repository secret و سه secret زیر را اضافه کنید:
   - `TELEGRAM_BOT_TOKEN`: توکن جدید BotFather (توکن افشاشده قبلی را باطل کنید)
   - `ADMIN_ID`: شناسه مدیر
   - `CHANNEL_ID`: `@go0dn`
4. در Actions، workflow را فعال کنید. برای آزمایش می‌توانید از Run workflow استفاده کنید.
5. ربات باید در کانال ادمین و دارای مجوز ارسال پیام باشد.

## رفتار
- حدود ۷:۳۰ صبح: پیش‌نویس صبح برای مدیر
- ۸ صبح: انتشار فقط اگر تأیید شده باشد
- حدود ۲۳:۳۰: پیش‌نویس شب برای مدیر
- ۰۰:۰۰: انتشار فقط اگر تأیید شده باشد
- مدیر می‌تواند با دکمه تأیید یا رد تصمیم بگیرد.

## محدودیت‌های مهم
- این یک راه‌حل آزمایشی و بدون هزینه API است، نه سرویس حرفه‌ای با تضمین uptime.
- GitHub اعلام می‌کند اجرای زمان‌بندی‌شده ممکن است در زمان شلوغی با تأخیر انجام شود یا حتی اجرا نشود. این workflow هر ۵ دقیقه اجرا می‌شود؛ بنابراین ساعت انتشار دقیق تضمین نیست.
- برای مخزن عمومی، کد و متن‌های موجود در مخزن برای همه قابل مشاهده‌اند؛ secrets در GitHub Secrets باقی می‌مانند و در کد نوشته نمی‌شوند.
- GitHub ممکن است workflow زمان‌بندی‌شده مخزن عمومی را پس از ۶۰ روز بدون فعالیت مخزن غیرفعال کند.
- این نسخه ویرایش متن از داخل تلگرام ندارد؛ فقط تأیید و رد دارد. متن‌های جدید را می‌توان بعداً به بانک `BANK` اضافه کرد.
- برای اجرای پایدارتر، سرویس میزبانی دائمی معمولاً هزینه دارد.
